# 🎮 Prisoner's Dilemma AI Simulator

An advanced AI-powered Game Theory simulator built using Python, Gradio, Matplotlib, and Pandas.

This project simulates the famous Prisoner's Dilemma problem from Game Theory using multiple AI strategies and human interaction modes.

---

# 🚀 Features

- 🤖 AI vs AI Simulation
- 👤 Human vs AI Gameplay
- 🎯 Multiple AI Strategies
- 📈 Real-Time Score Progression Graph
- 📊 Cooperation & Betrayal Statistics
- 💾 CSV Match Export
- 🌙 Dark Mode Interface
- 🏆 Winner Detection System

---

# 🧠 Implemented AI Strategies

- Always Cooperate
- Always Betray
- Random Strategy
- Mostly Cooperate
- Mostly Betray

# 📊 Game Theory Concept

The Prisoner's Dilemma is a classic problem in Game Theory where two players independently choose whether to:

- Cooperate
- Betray

Their choices determine rewards or penalties based on the payoff matrix.

This simulator demonstrates how different AI strategies behave over repeated interactions.
